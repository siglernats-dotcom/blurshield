01

¿Qué es BlurShield?

BlurShield es una extensión de Google Chrome que permite a los usuarios ocultar información sensible en páginas web reemplazando el contenido en el DOM del navegador. Está diseñada para proteger datos como correos electrónicos, números de teléfono, claves API y otra información confidencial durante grabaciones de pantalla, videollamadas y transmisiones en vivo.

Esta política describe cómo BlurShield maneja la información del usuario.

02

Datos que NO recopilamos

BlurShield no recopila, almacena ni transmite ninguno de los siguientes datos:

  • Contenido de las páginas web que visitas
  • Datos personales como nombre, dirección o información de contacto
  • Historial de navegación
  • Contraseñas o datos de formularios
  • Información financiera o bancaria
  • Comunicaciones personales
  • Datos de salud o información sensible
Todo el procesamiento ocurre localmente en tu navegador. BlurShield no tiene servidores propios que almacenen información de usuarios.
03

Datos que SÍ utilizamos

BlurShield utiliza un mínimo de datos estrictamente necesarios para funcionar:

  • Estado de la suscripción — guardado localmente en chrome.storage.sync para recordar si tienes Premium activo
  • Contador de usos diarios — guardado localmente para controlar el límite del plan gratuito (5 por día)
  • Posiciones de las máscaras — guardadas en sessionStorage del navegador, solo durante la sesión activa
Estos datos nunca salen de tu dispositivo. Se almacenan exclusivamente en tu navegador Chrome y no se transmiten a ningún servidor.
04

Verificación de licencia Premium

Cuando activas una licencia Premium, BlurShield realiza una consulta a la API de Payhip para verificar que tu clave sea válida.

  • Solo se envía la clave de licencia que ingresaste
  • No se envía ningún dato personal adicional
  • La verificación ocurre una sola vez al activar
  • El resultado se guarda localmente en tu navegador
Payhip tiene su propia política de privacidad disponible en payhip.com/privacy. Al comprar una licencia, también aceptas los términos de Payhip.
05

Permisos de la extensión

BlurShield solicita los siguientes permisos de Chrome, estrictamente necesarios para su funcionamiento:

  • activeTab — para acceder a la pestaña activa donde el usuario quiere ocultar información
  • storage — para guardar localmente el estado de la licencia y el contador de usos
  • scripting — para ejecutar el código que reemplaza el contenido en el DOM de la página
  • host_permissions (<all_urls>) — necesario para que la extensión funcione en cualquier página web que el usuario elija
No usamos estos permisos para recopilar datos. Solo se utilizan para aplicar las máscaras de contenido que el usuario solicita explícitamente.
06

Terceros y servicios externos

BlurShield interactúa con los siguientes servicios externos:

  • Payhip — exclusivamente para verificar claves de licencia Premium. Ver: payhip.com/privacy
  • Google Chrome Web Store — para distribución de la extensión. Ver: policies.google.com/privacy

No compartimos datos con anunciantes, redes de rastreo ni ningún otro tercero.

07

Seguridad

Dado que BlurShield no recopila ni almacena datos en servidores externos, el riesgo de vulneración de datos personales es mínimo. Todo el estado de la aplicación se guarda localmente en tu navegador Chrome, bajo las mismas protecciones de seguridad que Google aplica a las extensiones.

08

Menores de edad

BlurShield no está dirigido a menores de 13 años. No recopilamos intencionalmente información de menores. Si eres padre o tutor y crees que un menor ha proporcionado información personal, contáctanos para eliminarla.

09

Cambios a esta política

Podemos actualizar esta política de privacidad ocasionalmente. Cuando lo hagamos, actualizaremos la fecha al inicio de esta página. Te recomendamos revisarla periódicamente.

El uso continuado de BlurShield después de cualquier cambio constituye tu aceptación de la nueva política.
